SCREEN AI — PRODUCT SPECIFICATION

What is Screen AI?

Screen AI is an AI assistant that understands what a user is doing on their device over time.

Instead of only taking a screenshot and answering a question, Screen AI continuously understands the user's workflow, remembers the current task and previous steps, and provides help when needed.

Core Loop:

Observe → Understand → Remember → Assist → Observe Again

How it should work:

1. Observe
Screen AI observes the user's screen and detects relevant changes.

2. Understand
AI analyzes what application the user is using, what is visible, and what the user appears to be doing.

3. Remember
AI maintains context about the ongoing task, previous steps, completed steps, and the current state.

4. Assist
AI can help through:
- Text
- Voice
- Visual guidance
- On-screen indicators

5. Continue observing
Screen AI keeps following the workflow so the user does not need to repeatedly explain what they are doing.

Future Vision:

Screen AI will eventually become an AI coworker.

With the user's permission, it can:
- Click
- Type
- Scroll
- Open applications
- Navigate websites
- Perform computer tasks
- Verify whether an action worked

Future Agent Loop:

Observe → Reason → Act → Verify → Observe Again

Important Principle:

Screen AI should understand the user's ongoing workflow and context, not just individual screenshots.
